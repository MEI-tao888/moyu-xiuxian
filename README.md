# 摸鱼修仙

> 等待 DSH、WorkBuddy 或 Codex 回复时，开一局古早对话修仙。

摸鱼修仙是一款面向 Windows 的离线桌面小游戏。它会只读本机上的会话记录，在检测到开发工具持续回复时弹出一个小窗；回复结束后窗口会停在屏幕上，等你自己按 `Esc` 或点击“暂歇”收起。游戏进度逐回合保存，下次继续。

游戏的原则很简单：陪你等回复，不打断工作。

## 主要特性

- **三秒防抖**：忙碌持续约 3 秒才弹出，短暂工具调用不会打扰。
- **合并多工具状态**：DSH、WorkBuddy、Codex 前后脚或同时回复时只算一段思考，不会重复弹窗。
- **长思考续接**：已观察到的长回合允许中途较长时间不写文件，不会被拆成多次思考。
- **主动关闭冷却**：自动弹出后很快关闭，会在 1 小时内抑制下一次自动弹出；托盘手动打开不受影响。
- **不抢焦点**：自动弹出使用 `SW_SHOWNOACTIVATE`，不会把正在输入的窗口顶走。
- **回复结束不自动关闭**：标题变为“修仙 · 回复已完成”，由你决定何时收起。
- **托盘常驻**：可暂停监测、选择监测哪些工具、设置开机自启和手动打开窗口。
- **纯离线、零第三方依赖**：只使用 Python 标准库和 Windows 自带的 tkinter/ctypes。
- **连续短篇剧情**：事件按境界分层，共 208 个事件；每幕三回合左右，支持前情回看。
- **可靠存档**：每回合原子写入 `save.json`，并保留 `save.json.bak` 备份；主档损坏时自动回退备份。

## 运行环境

- Windows 10/11
- Python 3.9 或更高版本（需包含 `tkinter`）
- 不需要联网，不需要安装第三方包

目前检测器按各工具的本地记录格式工作，只读下列路径：

| 工具 | 读取位置 | 判定方式 |
| --- | --- | --- |
| DSH | `~/.dsh/storages/session_projcache/sessions/session-*.json` | `openTurnStartSeq` 回合标记与文件更新时间 |
| WorkBuddy | `~/.workbuddy/projects/*/*.jsonl` | 末条有效业务记录和文件更新时间 |
| Codex | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` | `task_started` 与完成/中止标记 |

检测器不会写入、修改或删除这些目录中的文件。

## 下载与启动

在 GitHub 页面选择 **Code → Download ZIP**，解压到一个固定目录。也可以使用 Git：

```powershell
git clone <仓库地址>
cd 摸鱼修仙
```

双击 `启动修仙.bat`，或在 PowerShell 中运行：

```powershell
pythonw xiuxian.py
```

程序会在后台常驻托盘。DSH、WorkBuddy 或 Codex 持续回复约 3 秒后，修仙窗口会自动出现在右下角。

首次使用建议先运行试玩模式确认字体和窗口大小：

```powershell
python xiuxian.py --demo --data .\demo_data
```

试玩模式不读取任何工具状态，也不会碰正式存档。`试玩.bat` 是同一命令的快捷方式。试玩完成后可删除 `demo_data` 目录。

### 指定存档目录

默认存档与 `xiuxian.py` 位于同一目录。若不希望把进度放在程序目录，可以指定目录：

```powershell
pythonw xiuxian.py --data "$env:APPDATA\摸鱼修仙"
```

一个目录只使用一个 `save.json` 存档，不提供多存档位。请勿把个人 `save.json` 提交到公开仓库。

## 托盘菜单

右键托盘羽毛图标可以：

- 打开游戏窗口（手动打开时允许获得焦点）；
- 暂停/恢复监测；
- 单独开启或关闭 DSH、WorkBuddy、Codex 监测；
- 设置或取消开机自启；
- 重置存档；
- 退出程序。

自动弹出的窗口不会抢焦点。按 `Esc`、点击“暂歇 · Esc”或窗口右上角 `×` 可收起；回复结束后不会自行关闭。

## 游戏规则

每回合从“稳 / 搏 / 险”三种选择中择一。失败不会降低境界，连续失败会触发保底；修为、气运、灵石和剧情进度会自动保存。每次回复通常推进 1–3 回合，适合在等待间隙随手游玩。

## 从源码运行与测试

项目没有构建步骤，入口是 `xiuxian.py`。运行完整测试：

```powershell
python -m unittest discover -v
```

测试覆盖游戏结算、存档备份、事件模板、故事续接、检测器防抖、多工具合并、长思考续接、Codex 边界和弹窗冷却策略。

## 隐私与权限

摸鱼修仙不联网、不上传日志、不调用 LLM。检测器只读取本机指定目录中的会话文件，并只在自己的存档目录写入 `save.json`、备份和窗口位置。开机自启功能仅写入当前用户的 Windows 注册表 `Run` 项，关闭后可随时取消。

## 已知限制

- 检测器依赖 DSH、WorkBuddy、Codex 当前的本地记录格式；工具升级后格式改变时，可能需要更新适配器。
- 项目只支持 Windows；Linux/macOS 没有托盘和窗口行为保证。
- tkinter 字体显示取决于系统安装的中文字体；Windows 10/11 推荐使用默认的“微软雅黑 UI”。
